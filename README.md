# 猫猫藏藏 (CatHide)

轻量、纯粹的 macOS 原生图片打码与隐私遮挡工具（Swift 6 + SwiftUI + AppKit + CoreImage）。

## 核心特性

- **多种遮挡风格与工具（互不干扰混合使用）**：支持**马赛克**、**高斯模糊**、**纯色遮挡**（黑 / 灰 / 白）三种效果与细 / 中 / 粗强度调节，可在同一张图片的不同区域自由混用不同效果与强度，各笔划独立保留各自效果、互不影响；提供**涂抹画笔**（支持无极滑块与点击输入精确像素大小）、**框选矩形**与**橡皮擦**，并支持撤销 / 重做与清空。
- **自动识别隐私信息（`A`）**：用 Apple Vision 在本机识别中英文文字与二维码 / 条形码，找出手机号、邮箱、证件号、银行卡、地址、姓名（含表格与家庭成员栏）、生日、车牌、社交账号与各类编号，先以方框预览；点方框可跳过、按类别整体开关，确认后一次打码、撤销一次即可还原。手写文字也能识别大部分。不联网、不上传。
- **PDF 打码**：支持加密 PDF（先询问密码）；按需渲染当前页及相邻页，底部缩略图条按页显示，标题旁翻页器与 PageUp / PageDown 翻页；自动识别可一次处理整个 PDF。导出为只含图像的 PDF（保持原页面尺寸，被遮住的文字不会留在文件里），也可只导出当前页为 PNG / JPEG。
- **非破坏性裁剪与旋转**：支持自由比例、原图比例、1:1、4:3、16:9 裁剪与顺时针 90° 旋转，随时撤销/还原，全分辨率无损导出。
- **原生多图工作流**：支持拖放单图、多图或整个文件夹及剪贴板粘贴；底部 Dock 悬浮波浪缩略图条支持拖动快切、后台预加载，放大视图后自动收起为紧凑计数胶囊，并可一键展开为沉浸式液态玻璃 Dock。
- **精准交互与触控板适配**：支持触控板双指平移与捏合缩放、鼠标滚轮缩放（兼容 macOS 原生滚动方向与 MOS 等第三方反转工具）、空格/右键拖动画布、方向键微调，以及按住 `\` 键或顶部眼睛图标实时对比原图。
- **隐私元数据清理**：导出 PNG / JPEG 时默认剥离 EXIF / GPS / 拍摄设备等隐私元数据（可在设置中关闭），导出单张后自动推进到下一张未处理图片，并支持批量导出所有已修改图片。
- **macOS 26 Liquid Glass 原生质感**：支持自动匹配 macOS 26+ Liquid Glass 工具栏与悬浮胶囊设计，并兼容 macOS 14+ 常规磨砂材质；支持白天 / 黑夜 / 跟随系统主题一键循环切换。
- **应用内快捷键自定义**：打开设置 (`⌘,`) 即可自由重设应用内所有工具、文件、编辑与切图快捷键，绝不抢占系统或其他应用全局热键。

## 系统要求

- macOS 14.0（Sonoma）及更高版本（在 macOS 26 及以上自动启用原生 Liquid Glass 视觉效果）
- Swift 6.0+ / Xcode Command Line Tools（用于从源码编译）

## 构建与运行

### 运行单元测试

```bash
swift test
```

### 打包并安装 `.app`

```bash
git clone https://github.com/uncat2310/CatHide.git
cd CatHide
bash Scripts/build_app.sh
```

脚本会自动编译 release 二进制、生成应用图标、配置 Info.plist 与多语言显示名称，并签名安装到 `/Applications/CatHide.app`（可通过环境变量 `TARGET_APP_DIR=/custom/dir` 自定义输出目录）。
